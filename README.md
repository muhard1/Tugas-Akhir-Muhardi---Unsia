Judul : Klasifikasi Bahaya Senyawa berdasarkan Notasi SMILES menggunakan Algoritma Random Forest dengan Pendekatan Problem Transformation

Repository ini berisi source code dan dataset yang digunakan dalam penelitian Tugas Akhir. Pada penelitian ini dilakukan perbandingan performa algoritma Random Forest dengan pendekatan Problem Transformation (Binary Relevance, Classifier Chain, dan Label Powerset).

Hasil penelitian menunjukkan bahwa metode Classifier Chain dengan fitur sebesar 20% memberikan performa terbaik.
